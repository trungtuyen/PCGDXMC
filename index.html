Cách dùng dành cho giáo viên/cán bộ PCGD

  1. Giáo viên điều tra và hoàn thiện file Excel có sheet MauNhapLieu như mẫu Bản Cháng.xls.
  2. Chọn một file để tổng hợp một thôn, hoặc chọn nhiều file để gộp nhiều thôn/xóm.
  3. Nhấn Phân tích và tạo biểu. Phần mềm tự nhận năm trong file nếu ô năm điều tra có dữ liệu.
  4. Kiểm tra tab Soát lỗi. Mỗi lỗi có file nguồn + số dòng để quay lại sửa phiếu.
  5. Nhấn Xuất toàn bộ biểu Excel để tải bộ tổng hợp về máy.
